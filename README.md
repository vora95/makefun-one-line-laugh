A small program that writes one short text (124 characters) to `/output/entry.txt`: a light, funny take on everyday life — a washing machine that eats one sock per load, which the narrator has decided is raising a family somewhere warm, and honestly, good for it.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
